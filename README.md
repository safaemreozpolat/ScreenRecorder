# ScreenRecorder
Since I was tired of paid screen recording programs, I wrote a program for myself—and anyone else who might find it useful—that records screen videos, captures microphone and system audio, and takes screenshots. It’s both free and easy to use. Enjoy!


ScreenRecorder
You can run the ScreenRecorder .exe file, located in the dist folder within the ScreenRecorder folder.

It doesn’t require any installation; you can create a shortcut on your desktop or assign it a keyboard shortcut of your choice.

Simply specify a folder to save the screenshots. 

Finally, start recording
